# Troubleshooting

Every error and warning the scripts and hooks print starts with a code (`IHC0xx`) and is followed by a `fix:` line. This page lists every one of them, generated from the code (`scripts/lib/messages.mjs`), so it always matches what you see.

Set `HELP_CENTER_DEBUG=1` to also print the stack trace of an unexpected error.

## Symptoms without a code

| Symptom | Cause | Fix |
|---|---|---|
| No space between sections on Intercom | The article was published by something else, without spacer paragraphs | Re-publish it with `publish.mjs`; it inserts the spacer Intercom's own editor uses |
| The title shows twice | The body starts with `# Title` and was published by another tool | Re-publish; the leading H1 is stripped |
| Readers see raw `**` or pipe characters | Markdown was pasted into Intercom instead of converted | Re-publish with `publish.mjs` |
| A second copy of an article appeared | `intercom_id` was not committed after the first publish, and adoption was off (`--no-adopt`) | Delete the copy in Intercom, keep the id in the file, commit it |
| A command is not found (`/intercom-help-center:audit`) | The plugin is not installed or not enabled in this project | `/plugin` to check; reinstall with the commands in the README |
| The hooks never fire | Hooks disabled (`disableAllHooks`, `HELP_CENTER_HOOKS=off`, `hooks.enabled: false`), or the plugin is disabled | Check those three places |
| The stale reminder never fires | The edited file is not listed in any article's `sources:`, or `.help-center/config.json` does not exist | Add `sources:`; run setup |
| The audit says every feature is uncovered | The features have no `label`, `keywords` or `strings` that appear in your articles | Add them to the manifest (see docs/CONFIG.md) |
| Orphans that are clearly about a real feature | Same cause: the feature's words do not appear in the article | Add `keywords`/`strings` to that feature, or map the file with an `article:` cell |
| `gh` works in your terminal but not for Claude | Claude Code started from a different shell or environment | Start `claude` from the terminal where `gh auth status` works |
| Setup finds no strings | Your strings live in an unusual place or format | Pass `--strings path1,path2`; supported: JSON, YAML, .po, .strings, Android XML |

### Intercom access

| Code | Message | Cause | Fix |
|---|---|---|---|
| **IHC001** | INTERCOM_API_TOKEN is not set. | The script needs to talk to Intercom and no token is in the environment. | `export INTERCOM_API_TOKEN=...` in this shell only (never put it in a file you commit). See docs/SETUP.md, step 3. |
| **IHC002** | Intercom rejected the token (401) for region {region}. | The token is wrong, revoked, or belongs to a workspace in another data region. | Run `/intercom-help-center:setup` (or `node scripts/doctor.mjs`): it tries US, EU and AU and tells you which region the token belongs to. Set INTERCOM_REGION or `intercom.region` in config. |
| **IHC003** | The token cannot read {what} (403). | The Intercom app behind the token lacks the read permission. | In Intercom's Developer Hub, open your app > Authentication and enable the 'Read and List articles' scope, then use the refreshed access token. See docs/SETUP.md, step 3. |
| **IHC004** | The token cannot write {what} (403). | The token has read access only. Setup cannot test write access without writing, so this shows up on the first real publish. | Enable the 'Read and Write Articles' scope on the Intercom app (Developer Hub > your app > Authentication) and re-run. Nothing was changed by the refused call. |
| **IHC005** | Still rate limited by Intercom after {retries} retries. | A very large Help Center, or another integration using the same token at the same time. | Wait a minute and re-run the same command. Reads are cached in the snapshot and publishing is resumable. |
| **IHC006** | {method} {path} failed mid-write: {detail} | The network or Intercom failed while a write was in flight, so it may or may not have landed. | Re-run the same command. The publisher re-reads Intercom first and adopts an article it already created instead of creating a second copy. |
| **IHC007** | INTERCOM_REGION "{region}" is not one of us, eu, au. | Typo in the region. | Use `us` (api.intercom.io), `eu` (api.eu.intercom.io) or `au` (api.au.intercom.io). |
| **IHC008** | Intercom API error: {detail} | An unexpected response from Intercom. | Re-run once. If it repeats, open an issue with the command and the status code (never the token). |
